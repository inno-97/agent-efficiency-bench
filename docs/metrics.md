# 측정 규칙

| 항목 | 기록 |
|---|---|
| 품질 | 최초·최종 테스트 통과/전체 수, 완료 여부, 미해결 결함 |
| 토큰 | 도구가 제공하는 입력·출력·캐시·추론 및 전체 사용량, 원본 출처 |
| 시간 | 최초 제출·수정 포함 전체 경과 시간, 사람 응답·한도 대기 별도 |
| 개입 | 추가 지시·승인·질문 답변 횟수와 사람의 소요 시간 |
| 재작업 | 수정 라운드 수, 새로 발생한 회귀 |
| 비용 | 실제 관측 API 비용·추가 지출, 구독 고정비는 별도 |
| 재현 정보 | 과제 버전·시작/최초/최종 커밋, 환경·명령·설정 |

미관측 값은 null로 표시하고 0이나 추정값으로 채우지 않습니다. 토큰 집계 의미와 캐시·추론 포함 관계를 명시하며 항목을 무조건 합산하지 않습니다. 서로 다른 모델의 토큰 수가 동일한 비용·계산량을 뜻하지 않습니다.

협업은 전체 참여 에이전트의 사용량을 포함하고 에이전트별 내역도 남깁니다. 도구가 하위 에이전트를 이미 포함하는지 확인해 중복 집계를 피합니다.

서비스별 한도 퍼센트를 합산하거나 API 정가를 구독 실지출로 환산하지 않습니다. 전체 경과 시간에는 컴파일·모델 응답 대기를 포함합니다. 한도/사람 대기는 별도 내역으로 함께 보고합니다.

종합 점수는 도입하지 않습니다. 동일 과제·버전·조건에서 완료 여부를 먼저 보고, 완료 실행의 토큰·시간·개입을 나란히 비교합니다.
