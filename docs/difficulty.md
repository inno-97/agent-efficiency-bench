# 난이도 기준

| 레벨 | build | fix |
|---|---|---|
| L1 | 단일 화면·로컬 상태와 저장 | 좁은 범위의 상태·로직 오류 |
| L2 | 여러 화면·검증·집계·영속 데이터 | 화면·모듈 간 불일치 |
| L3 | 인증 또는 기기 기능 등의 경계 | 인증·파일·저장 경계 결함 |
| L4 | 권한·동기화 등의 상호작용 | 권한·동시성·동기화 결함 |

레벨은 잠정 분류입니다. 과제 하나의 결과를 해당 난이도 전체 성능으로 일반화하지 않습니다. 웹과 모바일의 동일 레벨도 직접적인 동등성을 의미하지 않습니다.

각 과제는 독립 실행할 수 있습니다. 난이도 레벨과 과제 내부 구현 단계는 별개입니다.
